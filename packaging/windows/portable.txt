StitchFoundry portable mode

While this file sits next to stitchfoundry.exe, StitchFoundry keeps its preferences, swatch and
graphic style libraries, added fonts, crash-recovery files and logs in the StitchFoundryData folder
beside it, and writes nothing to %APPDATA%. Copy the whole folder to move StitchFoundry with its
settings. The first time StitchFoundryData is created, any settings already in
%APPDATA%\StitchFoundry are copied into it; the originals are left where they were.

Keep this folder somewhere only you can write to: whoever can write here decides your settings,
including the plug-ins and fonts folders StitchFoundry loads from, and the Data Recovery copies of
your unsaved documents are kept here too.

Delete this file to use the normal per-user settings folder (%APPDATA%\StitchFoundry) instead.
If StitchFoundryData can't be written (for example on a read-only drive), StitchFoundry logs a
warning and uses %APPDATA%\StitchFoundry instead.
